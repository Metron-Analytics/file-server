# Security

If you find a security problem in the File server or the app, such as a way to see documents or accounts you should not, please don't open an issue or a discussion: those are public.

E-mail **archive@metron-apps.eu** with "Security" in the subject, and describe:

- what you found and how to reproduce it, with invented data only;
- the server release (Account screen or `/api/health`) and the app version;
- whether the server uses the `lan` or the `public` profile.

You'll get an answer within a week. Please give us time to release a fix before you tell others about it. We'll credit you in the release notes if you'd like.

Updates with security fixes are released like any other release; the release notes say so. Keep your server up to date.
